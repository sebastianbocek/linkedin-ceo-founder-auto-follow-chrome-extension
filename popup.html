Cómo usar

  1. Abre My Network → Grow y pulsa Iniciar.
  2. La extensión abrirá Show all si está disponible, y buscará tarjetas al desplazarse.
  3. Define un máximo de acciones; usa 0 para continuar hasta detenerla.
  4. Usa Detener para finalizar en cualquier momento.
